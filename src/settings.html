OpenAI cloud setup

Uses GPT-4.1 for answers and images, and GPT-4o mini Transcribe for speech. Captured speech and screen content are sent to OpenAI while those features are on. API billing is separate from ChatGPT. The key is saved in this app's local settings.

AI model Ollama · LM Studio · OpenRouter · OpenAI · Groq — any OpenAI-compatible API
Transcription (speech → text)

Local default: run start-stt.bat (faster-whisper, port 8399). Cloud alternatives: Groq (whisper-large-v3-turbo) or OpenAI (whisper-1) — set their URL + key.

Behavior
Generate an answer whenever a question is detected Live captions while people talk, and start answering a question before they finish it
Screen understanding reads your screen with a vision model
When the 👁 toggle is on in the overlay, read the screen periodically; answer on-screen questions automatically seconds

Needs a vision-capable model — text models can't read images. Default pick: qwen3-vl:2b (does both chat and vision; ~2 GB). Heavier: qwen2.5vl:7b, minicpm-v. The ⤓ button starts Ollama and installs it if missing.
